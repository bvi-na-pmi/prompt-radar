# Промпт-Радар
**Видео-демо:** https://disk.yandex.ru/client/disk/%D1%85%D0%B0%D0%BA%D0%B0%D1%82%D0%BE%D0%BD%20%D0%BC%D0%B8%D1%84%D0%B8

Аналитическая платформа для учёта и классификации ИИ-запросов сотрудников.
Система автоматически определяет категорию каждого промпта через Gemini API,
рассчитывает экономию рабочего времени и ФОТ с учётом стоимости ИИ-обработки.

**Стек:** React + Vite + Tailwind CSS + Recharts (frontend) · Express + Gemini API (backend)

## Быстрый старт

```bash
npm install
npm run dev
```

Сервер запускается на `http://localhost:3000`, Vite-дев-сервер на `http://localhost:5173`.

## Вкладки

| Вкладка | Назначение |
|---------|------------|
| **ИИ-Копилот** | Чат с агентом для формирования сводок, отчётов и анализа данных |
| **Сводка** | Общая картина: топ пользователей, активность по отделам, лента последних запросов |
| **Реестр** | Полный список всех запросов с фильтрацией по категории, статусу, отделу |
| **Аналитика** | Динамика запросов, распределение по категориям, потребление токенов, экономический эффект (грязный / чистый ФОТ) |

## Архитектура

```
src/
├── components/
│   ├── DashboardOverview.tsx   — сводка (пользователи, отделы, активность)
│   ├── AnalyticsChartsView.tsx — аналитика (категории, экономика, тренды)
│   ├── RequestFeedView.tsx     — реестр запросов
│   ├── CopilotChatView.tsx     — ИИ-копilot
│   └── Sidebar.tsx             — боковое меню
├── data/
│   └── mockRequests.ts         — генератор тестовых данных
├── types.ts
├── App.tsx
└── index.css
server.ts                       — Express + Gemini API
config.financial.json           — коэффициенты для расчёта экономии
```
